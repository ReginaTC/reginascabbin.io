# 内容目录

这个目录是个人小屋的长期内容仓库。现在页面还只是静态框架，后续可以把这里的 Markdown 文件接成文章详情页、搜索索引或 RSS。

## 推荐结构

- `ideas/`：想法、灵感、观察、备忘
- `diary/`：日记、生活记录、情绪天气
- `work/`：干货分享、项目复盘、工具笔记、方法清单

## 命名格式

建议使用：`YYYY-MM-DD-标题.md`

## 单篇文章草稿模板

```md
---
title: 文章标题
date: 2026-05-11
tags: [想法, 写作]
type: idea
---

一句话摘要。

## 起因

## 过程

## 暂时结论
```
